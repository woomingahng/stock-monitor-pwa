# Stock Monitor 편의 기능 추가 완료

요청하신 세 가지 기능을 모두 구현 완료했습니다. 앱을 새로고침(`npm run dev`) 하시면 바로 테스트해 보실 수 있습니다!

## 1. 하단 종목 리스트 빠른 추가 (더블 클릭)
하단에 모니터링 중인 종목 리스트가 뜰 때, 각 항목 좌측에 있는 **종목 코드(검은색 뱃지)** 영역을 **더블 클릭**하면, 상단 조회 영역에 해당 종목이 자동으로 설정됩니다. 기존처럼 일일이 종목명을 검색창에 타이핑할 필요가 없어졌습니다.

## 2. 퍼센트(%) 기반 알림 금액 설정 지원
알림을 추가할 때 "목표가 입력" 칸에 금액(원) 뿐만 아니라 퍼센트(%)도 입력할 수 있습니다. 
예를 들어 특정 종목이 현재 `80,000`원일 때,
- `10%` (또는 `+10%`) 입력 시: 현재가 대비 10% 오른 `88,000`원으로 목표가가 자동 계산되어 설정됩니다.
- `-5%` 입력 시: 현재가 대비 5% 하락한 `76,000`원으로 목표가가 자동 계산되어 설정됩니다.

## 3. 최상단/최하단 돌파 시 3% 자동 알림 추가
어떤 종목의 주가가 지속 상승/하락하여 **기존에 설정한 가장 높은 목표가(최상단)**를 뚫거나 **가장 낮은 목표가(최하단)**를 뚫을 경우, 알림이 울림과 동시에 **돌파 순간의 현재가 기준으로 3% 위(또는 아래)에 새로운 알림이 자동으로 생성**됩니다. 이를 통해 급등/급락하는 종목을 놓치지 않고 계속 추적할 수 있습니다.

---

> [!TIP]
> 앱이 실행 중인 상태에서 종목 뱃지에 마우스를 올려 더블 클릭해 보시고, 목표가 입력 창에 `5%` 또는 `-3%`를 입력하여 잘 동작하는지 확인해 보세요!
