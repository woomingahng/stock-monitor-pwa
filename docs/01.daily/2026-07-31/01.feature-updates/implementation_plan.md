# PRD: 모니터 앱 편의 기능 및 자동 알림 추가

## 🎯 목표 & MVP
사용자의 편의성을 높이기 위해 하단 종목 목록에서 빠른 종목 선택을 지원하고, 퍼센티지(%) 단위의 알림 금액 설정을 도입합니다. 또한, 설정한 최상단/최하단 알림 가격이 돌파되었을 때 자동으로 다음 알림(3% 간격)을 설정하여 지속적인 모니터링이 가능하게 합니다.

## ⚠️ 리스크 & 테스트 계획

### 리스크
- **% 입력 파싱 로직**: 사용자가 "10%", "+10%", "-10%" 등 다양한 형태로 입력할 수 있습니다.
- **자동 알림 무한 생성**: 급등/급락 시 가격 폴링 주기에 따라 여러 번 알림이 중복 생성되지 않도록 동시 처리 로직에 유의해야 합니다.
- **최상단/최하단 기준**: 어떤 알림이 최상단/최하단인지 판별하는 기준이 명확해야 합니다.

### 테스트 계획
1. **유닛/수동 테스트**:
   - 하단 종목 리스트의 코드 영역을 더블 클릭 시 종목 등록 화면으로 즉시 전환되는지 확인.
   - 금액 입력 칸에 `10%`, `-5%` 입력 후 등록 시 현재가 대비 정확한 가격으로 알림이 등록되는지 확인.
2. **통합 테스트**:
   - 강제로 가격을 수정하여(또는 Mocking) 등록된 최상단 알림 돌파 시 새로운 알림(3% 위)이 자동으로 목록에 추가되는지 확인.
